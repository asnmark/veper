# Veper MVP Implementation Plan

> **For agentic workers:** implement inline with test-driven development; execute tasks in order and retain the progress ledger at `.superpowers/sdd/2026-10-20-veper-mvp/progress.md`.

**Goal:** Build a source-grounded live intelligence desk for Slovenian journalists.

**Architecture:** One TypeScript application: Fastify API and background poller, SQLite persistence, React/Vite interface. Public RSS/Atom excerpts are the only news text retained or sent to Gemini; there is no separate queue, vector database, feed scraper, or chatbot.

**Tech Stack:** Node 24, TypeScript, React, Vite, Fastify, SQLite (`better-sqlite3`), `fast-xml-parser`, Google GenAI SDK, Vitest, Playwright.

**Spec:** `docs/product-brief.md`.

## Global Constraints

- Run on Node 24 or newer; TypeScript strict mode is required.
- User-facing product copy is Slovenian.
- Poll only configured public RSS/Atom sources. Keep title and description excerpts to 900 characters; do not fetch article pages.
- Preserve publisher time separately from capture time.
- AI analysis is background-only and bounded to changed evidence. Show a claim only after local source ID/exact-quote checks and an explicit second Gemini support review; label the result as an AI editorial draft.
- Never create fake live records. Fixtures may appear only in tests.
- Test commands: `npm test`, `npm run typecheck`, `npm run build`, `npm run test:e2e`.

## Review Focus

- Malformed or adversarial feed XML → reject the feed item safely and retain prior data.
- Duplicate GUID/link and changed source item → idempotent upsert plus a traceable revision.
- Unknown article ID or quote absent from the excerpt → discard that AI statement.
- Gemini timeout or missing key → retain raw reporting, expose explicit status, never fabricate a fallback.
- Keyboard use and narrow viewport → search, story selection, and evidence remain reachable.
