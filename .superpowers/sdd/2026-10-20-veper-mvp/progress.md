- Ruling: replace the earlier PostgreSQL + pgvector + pg-boss design with one SQLite-backed service — the expected public-feed volume and single-workspace MVP do not justify three independently operated services; a SQLite adapter still allows a later Postgres migration. Cost if wrong: scaling to multiple app replicas will require a storage migration.
- Ruling: use `better-sqlite3` rather than Node's built-in `node:sqlite` — Node 24.19 documents the built-in module at Stability 1.2 (Release candidate), while `better-sqlite3` 13.0.3 supports Node >=22. Cost if wrong: a native module increases install/build friction.
- Ruling: keep ambiguous/low-similarity stories separate — false clustering can mislead editorial decisions; Gemini comparison is restricted to validated source excerpts. Cost if wrong: some cross-language links may be missed.
- Ruling: operate in the mounted `work` branch because this repository is genuinely unborn (no commit to branch from) and the cloud workspace is already isolated; do not create a second worktree. Cost if wrong: environment-level isolation is weaker than a worktree, though there is no pre-existing source to overwrite.
- Ruling: use English in `AGENTS.md` and machine-facing docs, Slovenian in all product/user copy — agent docs are optimized for compact execution while newsroom output stays native-language. Cost if wrong: a Slovenian-only agent ecosystem may need translation.
